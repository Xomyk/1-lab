# Лабораторная работа №1: Отношения между классами (Композиция)

## 🎯 Цель работы
1. Научиться проектировать отношения между классами: композицию, агрегацию и ассоциацию.
2. Освоить реализацию композиции (поля-объекты, вложение структур).
3. Понять разницу между композицией и агрегацией с точки зрения времени жизни объектов.
4. Получить навыки правильного управления памятью при разных типах отношений между классами.

## 📋 Вариант задания (Базовый уровень, Вариант 4)
*   **Класс «Целое»:** `University` (Университет).
*   **Класс «Часть»:** `Faculty` (Факультет).
*   **Поля класса «Часть»:** название, количество кафедр.
*   **Задание:** Реализовать два класса, связанных отношением **композиция** (часть не может существовать без целого). Продемонстрировать создание и уничтожение объектов.

## 📚 Теоретическая часть
*   **Композиция** — это отношение «часть–целое», при котором «части» не могут существовать без «целого». Целое полностью контролирует время жизни частей.
*   **Ключевая характеристика:** Часть умирает вместе с целым.
*   **Реализация в C++:** Через поля-объекты или контейнеры, хранящие объекты по значению (например, `std::vector<Faculty>`). При уничтожении объекта-владельца автоматически вызываются деструкторы всех его частей.

## 💻 Листинг программы (main.cpp)

```cpp
#include <iostream>
#include <string>
#include <vector>

using namespace std;

// ==========================================
// Класс "Факультет" (Часть)
// ==========================================
class Faculty {
private:
    string name;
    int departmentCount; // Количество кафедр

public:
    // Конструктор
    Faculty(const string& n, int count) : name(n), departmentCount(count) {
        cout << "  [+] Создан факультет \"" << name 
             << "\" (кафедр: " << departmentCount << ")" << endl;
    }

    // Деструктор
    ~Faculty() {
        cout << "  [-] Уничтожен факультет \"" << name << "\"" << endl;
    }

    // Метод для вывода информации
    void printInfo() const {
        cout << "    - Факультет: " << name 
             << ", Количество кафедр: " << departmentCount << endl;
    }
};

// ==========================================
// Класс "Университет" (Целое)
// ==========================================
class University {
private:
    string name;
    // КОМПОЗИЦИЯ: вектор хранит объекты Faculty по значению.
    // Университет полностью контролирует их время жизни.
    vector<Faculty> faculties; 

public:
    // Конструктор
    University(const string& n) : name(n) {
        cout << "=== Создан Университет \"" << name << "\" ===" << endl;
    }

    // Деструктор
    ~University() {
        cout << "=== Университет \"" << name << "\" ликвидируется ===" << endl;
        // Вектор faculties уничтожится автоматически, 
        // а вместе с ним вызовутся деструкторы всех факультетов.
    }

    // Метод добавления факультета
    // Объект факультета создается прямо внутри метода и копируется в вектор
    void addFaculty(const string& facultyName, int count) {
        faculties.emplace_back(facultyName, count);
    }

    // Вывод информации об университете
    void printInfo() const {
        cout << "\n--- Информация об Университете \"" << name << "\" ---" << endl;
        if (faculties.empty()) {
            cout << "  Факультетов пока нет." << endl;
        } else {
            for (const auto& faculty : faculties) {
                faculty.printInfo();
            }
        }
        cout << "--------------------------------------------------\n";
    }
};

// ==========================================
// Главная функция
// ==========================================
int main() {
    setlocale(LC_ALL, "ru");

    cout << "--- Начало программы ---" << endl;
    
    // Создаем университет
    University myUniversity("МГТУ им. Баумана");

    // Добавляем факультеты (они создаются внутри университета)
    myUniversity.addFaculty("Информатика и системы управления", 5);
    myUniversity.addFaculty("Робототехника и комплексная автоматизация", 4);
    myUniversity.addFaculty("Энергомашиностроение", 3);

    // Выводим информацию
    myUniversity.printInfo();

    cout << "--- Программа подходит к концу (выход из main) ---\n" << endl;
    
    // При выходе из main локальная переменная myUniversity уничтожается.
    // Сначала вызывается деструктор University, затем деструкторы Faculty.
    return 0;
}
